# FritoMusic Flutter 🎵

**FritoMusic Flutter** es una aplicación de música y reproducción de audio/streaming. 

### 🚀 Sobre este proyecto
Este proyecto fue originalmente desarrollado en **Kotlin / Android**, pero se ha migrado a **Flutter** con el propósito de:
- Explorar y aprender a fondo el lenguaje **Dart**.
- Probar las capacidades, rendimiento y versatilidad de **Flutter** en el desarrollo multiplataforma.
- Experimentar con la gestión de estado, reproducción de audio y consumo de APIs de streaming en este nuevo ecosistema.

---

### 🛠️ Tecnologías
- **Flutter** & **Dart**
- Reproducción de audio y streaming
- Arquitectura limpia y modular
